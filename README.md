# ImgDrift

A personal visual AI project space for image generation, generation logic, visual materials, and future AI image tools.

## Version

`v0.0.1` focuses on rebuilding the homepage of the original `instant-style` project into an ImgDrift project index page.

## What this version includes

- A new ImgDrift homepage identity
- English-first interface with a simple Chinese toggle
- Project index cards for Works, Visual Library, and Future Tools
- Placeholder sections for image-related works and visual materials
- Future tool cards for Image Upscale, Background Remover, and Text to Image
- A Sketch Prototype card kept as a lightweight reference to the original prototype
- GitHub platform link and placeholder entries for future social platforms
- A support placeholder for future donation display

## What this version does not include

- No image upload flow
- No Canvas multi-style image conversion
- No real AI API integration
- No user account system
- No payment or subscription system
- No contact form
- No independent portfolio, library, or tools pages yet

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- OpenNext for Cloudflare
- Wrangler

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cloudflare preview / deploy

The existing project keeps the original Cloudflare-oriented scripts:

```bash
npm run preview
npm run deploy
```

For safer review, deploy the `imgdrift-v0-0-1-homepage` branch as a preview first, then decide whether to merge into `master` for production.
